# divan sunumu

| Dosya | Ne |
|---|---|
| `divan-sunum.html` | Sunum. Tarayıcıda açın; internet gerekmez (ekran görüntüleri `../img/` altından). |
| `divan-sunum.pdf` | Aynı sunumun PDF'i (e-postayla göndermek, yazdırmak için). |
| `KONUSMA_NOTLARI.md` | Her slayt için ne anlatılacağı. |

**Kullanım:** `→` / `←` (ya da tıklama) sayfa değiştirir, `F` tam ekran, `Home` / `End` başa / sona.
Adres çubuğunda `#7` gibi bir sayı doğrudan o slayta gider. `Ctrl+P` → "PDF olarak kaydet" ile PDF
yeniden üretilebilir (kenar boşluğu: yok, arka plan grafikleri: açık).

Sunum `llm-degerlendirme` dalının durumunu anlatır (YTET/YGÖ, Jira `divan` label'ı,
`ULAK_FIX_PIPELINE=senaryo` dahil). Sayılar (test, prova, gereksinim) değişirse 18. ve 19. slaytları
güncelleyin.
